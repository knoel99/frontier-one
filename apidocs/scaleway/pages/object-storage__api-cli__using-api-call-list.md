In this page we index all available Scaleway Object Storage API requests.

## Before you start

To complete the following actions, you must have:

* [Owner](/en/docs/iam/concepts/glossary/#owner) status or [IAM permissions](/en/docs/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization

> **Note**
>
> When you use Object Storage directly with the API, you must generate an [Authentication Signature v4](/en/docs/object-storage/api-cli/generate-aws4-auth-signature/) beforehand.
