# AGENTS.md

Instructions for any coding agent working on this repository: the Frontier framework itself. (A mission's own
workspace gets its own AGENTS.md from the launcher.)

- `old/` is the previous race framework, kept for reference: do not edit it.
- Everything provider-specific goes in `config/providers.toml` (models, reasoning values, speed modes) and
  `config/prices.toml` (generated by `tools/update_prices.py`); everything harness-specific in
  `config/harnesses.toml` (launch) and `frontier/harnesses.py` (files). Code stays provider- and harness-neutral.
  Model ids and reasoning values come from the provider's `/models` endpoint and `python3 -m frontier ping`, never
  from memory.
- Generated files, never edited by hand: `catalog/*.json` (`tools/build_catalog.py`), `config/prices.toml`
  (`tools/update_prices.py`), and the harness files listed by `python3 -m frontier harnesses` (`CLAUDE.md`,
  `.mcp.json`, `.codex/`, `.agents/`, `.claude/`, `opencode.json`, … : `python3 tools/sync_harnesses.py`).
  Hand-written: `catalog/*-guide.md` (state the date and what was checked live), `roles/`, `prompts/`.
- A flow agents repeat belongs in `frontier/infra.py` as a ready-made function.
- The prompts (`prompts/`, `roles/`) state facts, requirements and evaluation, not strategy: the mission's AI
  decides how to work.
- The framework's tools are served to this repository's harness by the `frontier` MCP server
  (`python3 -m frontier.mcp`); the shell fallback is `bin/frontier call <tool> '<json>'`.
- Standard library only at run time (`huggingface_hub` only for publishing). Before committing:
  `python3 -m ruff check .`, `python3 -m pytest -q`, `python3 tools/sync_harnesses.py --check`.
- Write in English.
