# AGENTS.md

Instructions for any coding agent working on this repository (the framework itself, not an agent run by it).

- `old/` is the previous race framework, kept for reference: do not edit it.
- Everything provider-specific goes in `config/providers.toml`; code stays provider-neutral. Model ids and reasoning
  values come from the provider's `/models` endpoint and `python3 -m frontier ping`, never from memory.
- `apidocs/` is generated by `tools/fetch_api_docs.py`, except `apidocs/*/GUIDE.md` (hand-written; state the date
  and what was checked live).
- Standard library only at run time. Before committing: `python3 -m ruff check .` and `python3 -m pytest -q`.
- Write in English.
